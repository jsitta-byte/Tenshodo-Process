# Playbook 02 — Organizational Bootstrap

## Use when

The target operating model requires roles, governance, or capabilities that do not yet exist.

## Failure pattern

A transformation says:

> The CHRO must create the people system.

But there is no CHRO.

Or:

> The COO must design management governance.

But no one currently has that delegated role.

The target state becomes a prerequisite for creating itself.

## Method

Separate:

- target_owner_role;
- current_executor;
- adoption_authority.

Create a narrow transitional mechanism.

Possible current executors include:

- executive sponsor;
- temporary bootstrap steward;
- consulting engagement lead;
- chartered AI role conversation for build/propose work.

## Guardrails

Temporary authority should be:

- explicit;
- scoped;
- reviewable;
- supersedable;
- time/review bounded;
- unable to silently create permanent organizational authority.

## Output

The bootstrap phase should make the current organization legible enough to determine what permanent roles and operating mechanisms are actually needed.
